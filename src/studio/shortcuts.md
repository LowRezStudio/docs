# Keyboard shortcuts

On macOS, use Cmd wherever this page says Ctrl, except for Ctrl+Tab. **F1** shows this list in the
Studio, and the command palette (Ctrl+K) shows each command's shortcut.

## Everywhere

| Shortcut             | Action                                                                           |
| -------------------- | -------------------------------------------------------------------------------- |
| Ctrl+K, Ctrl+Shift+P | Command palette                                                                  |
| Ctrl+P               | Go to a package or an assembly table                                             |
| Ctrl+Shift+O         | Go to an object of the open package, or filter the rows of the open table        |
| Ctrl+F, Ctrl+Shift+F | Search every package                                                             |
| Ctrl+S               | Save (the project in a project, the current file into the game folder otherwise) |
| Ctrl+Shift+S         | Export a copy of the current file                                                |
| Ctrl+Alt+S           | Save as a workspace file                                                         |
| Ctrl+Alt+O           | Open a project or workspace file                                                 |
| Ctrl+O               | Open a package file                                                              |
| Ctrl+Shift+N         | New window                                                                       |
| Ctrl+Z               | Undo (outside text fields)                                                       |
| Alt+←, Alt+→         | Back, Forward (also the mouse side buttons)                                      |
| F1, Shift+?          | Keyboard shortcuts                                                               |

## Views, tabs and panes

| Shortcut                 | Action                                                        |
| ------------------------ | ------------------------------------------------------------- |
| Ctrl+1, Ctrl+2, Ctrl+3   | Packages, Assembly, Build the mod                             |
| Ctrl+T                   | Duplicate the tab                                             |
| Ctrl+W                   | Close the tab                                                 |
| Ctrl+Tab, Ctrl+Shift+Tab | Next, previous tab                                            |
| Ctrl+click, middle-click | Open a package, object, reference, result or row in a new tab |
| Ctrl+B                   | Hide or show the side pane                                    |
| Ctrl+J                   | Hide or show the details pane                                 |
| Ctrl+=, Ctrl+-, Ctrl+0   | Zoom in, out, reset                                           |

## Packages

| Shortcut    | Action                                                   |
| ----------- | -------------------------------------------------------- |
| Up, Down    | Move through the package list or the export tree         |
| Right, Left | Expand or enter a group; collapse it or go to its parent |
| Enter       | Expand or collapse                                       |
| Home, End   | First, last item                                         |
| Ctrl+H      | Find and replace in the package                          |
| Ctrl+D      | Duplicate the selected object                            |

## Assembly

| Shortcut                              | Action                                                |
| ------------------------------------- | ----------------------------------------------------- |
| Arrows, Tab                           | Move the cell cursor                                  |
| Enter, F2, typing                     | Edit the cell                                         |
| Enter / Tab / Esc (while editing)     | Commit and move down / commit and move right / cancel |
| Space                                 | Toggle a flag                                         |
| PageUp, PageDown, Home, End           | Page through the rows                                 |
| Ctrl+click, Shift+click, Shift+arrows | Mark rows                                             |
| Ctrl+C, Ctrl+V                        | Copy the marked rows, paste them as new rows          |
| Ctrl+Shift+Enter                      | New row                                               |
| Ctrl+D                                | Duplicate the selected row                            |
