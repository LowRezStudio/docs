# Tempest

Tempest is the community Paladins launcher built by [LowRezStudio](https://lowrezstudio.com).
It lets you download and play any Paladins release, install gameplay and script mods,
and host or join private servers — keeping the game playable even without official support.

## Start here

- New to Tempest? The current launcher guides live alongside this page as they are written.
- Looking for the previous launcher? Its documentation has been moved to
  [Tempest Legacy](/tempest-legacy/introduction), including the
  [console commands](/tempest-legacy/commands) reference and
  [FAQ](/tempest-legacy/faq).
- Want to build mods? See [UDK getting started](/udk/getting-started).
- Curious how the networking works? See the [Marshal introduction](/marshal/introduction).

Updates are announced on the [blog](/blog/) and in the community Discord.
